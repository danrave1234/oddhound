## Positioning (one sentence)

> **General AI browser agents can report a bug. Oddhound proves one, and proves the fix.**

**Who hurts today:** the first engineer or solo founder at a small SaaS. A vague ticket ("booking said saved but vanished") costs 1–3 hours to turn into reproducible steps, often ending in "can't reproduce". Their Playwright suite only checks the paths someone thought to write.

**Why it is different from ChatGPT agent mode, Claude computer use, Browser Use:**

| General browser agent | Oddhound |
|---|---|
| "I found a bug" may be wrong | `verified` only after two fresh replays break the rule **and** a valid neighbouring case still passes |
| "Looks fixed now" | Retest replays the **unchanged, hash-pinned** assertion; a changed check never counts |
| Runs anywhere, in your browser | Only sites you prove you own; fresh sandboxed Chromium per run, egress-filtered, no platform keys |
| Chat transcript | Proof chain + fix prompt for your coding AI + Playwright test + PR-ready fix receipt |
| Unbounded spend | $2/run reservation, daily ceiling, kill switch |

## What the three models agreed (and what was rejected)

| Idea | Decision | Why |
|---|---|---|
| **Proof Chain view** (replay 1, replay 2, valid case, retests, pinned hash) | **Built** | Packages the strongest existing engineering into one thing a judge reads in 10 s |
| **Bug report → verified reproduction** (text) | **Building** (core by Codex, UI by Claude) | Concrete industry pain ("can't reproduce"); reuses verified pipeline; negative result is honest |
| **Fix receipt** | **Built** as copyable Markdown, not a public page | Public pages need privacy/redaction work |
| Head-to-head benchmark vs general agents | Appendix only, if time | Self-authored ground truth looks unfair; costs hours of manual runs |
| Two-model jury (Muse Spark Open as skeptic) | **Dropped** | Same model lineage is not independent; deterministic replay already decides |
| Coverage gap vs existing Playwright suite | **Dropped** | A subsystem, not a 1-day feature |
| Voice bug reports (Muse Voice Transcribe) | **Dropped** | Decorative API-counting |
| Cream paper + serif + mono "case file" UI (proposed by both ChatGPT and Muse) | **Rejected** | The most common AI-generated look right now |
| **Orienteering course** visual language | **Built** | A run really is an ordered route through recorded states; marks come from data |

## What is built today (Nov 3)

- **Proof Chain** in the finding inspector and on the landing page (`packages/core/reports/proof-chain.ts`, `/api/findings/[id]/proof`). Trusted code decides the verdict and refuses retests that ran a changed assertion. 7 unit tests.
- **Fix receipt**: `?format=receipt`, Markdown table of every check with the pinned hash.
- **Landing page rebuilt** around a real recorded run: the agent's route drawn as an orienteering course (start triangle, numbered controls, straight legs, finish ring), a control sheet marking the page where a verified rule broke (from the saved assertion's tested path), real facts (actions, verified bugs, minutes, model cost), one finding's full proof, a "where a test script stops" comparison, and plain limits. Removed: product mock, chip cloud, numbered steps, icon features, CTA band.
- **Workspace:** ring gauges and sparkline replaced by one instrument line of plain numbers; Trail drawn as a course; results page is one category-filtered list instead of a card grid.
- **Palette:** course-overprint purple accent (#9b2378 light / #e57fc8 dark), neutral macOS greys, Overpass only for headings and control numbers.
- **Cost:** demo-target runs use `META_MODEL_DEMO` (contributor tier); owner sites use standard `META_MODEL`.
- **Bug report field** in run setup + API, results page shows the report and the trusted `report.verdict` (needs Codex's core branch merged).

## Cost plan (real savings only)

1. Demo target on the contributor tier: ~$0.04 instead of ~$0.45 per run. Synthetic data only.
2. Verification and retests are deterministic: $0 model cost, and the reason results are credible.
3. Prompt caching already in place (stable prefix, append-only history).
4. Modal scale-to-zero web/worker, sandbox destroyed per run; Neon Free.
5. Partner credits (Baseten/Fireworks) do **not** lower the per-token price; use one only as a demonstrated Meta-model fallback.
6. Not a saving: batching actions (raised recall but cost ~40% more per run).

## Biggest risk: "doesn't work" during judging

A judge clicks once, waits on a cold start, sees zero findings. Mitigations:
- Landing defaults to a **pinned real recorded run** (course + proof) that needs no inference; live demo stays one click away.
- One golden production run after freeze, on Meta inference, with a retest on the corrected build.
- Rehearse signed out in a private window from another network before submitting.
